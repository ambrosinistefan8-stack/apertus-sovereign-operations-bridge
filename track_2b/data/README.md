# Synthetic demonstration data

The five fixture sets are defined in `../src/app/fixtures.py`. They describe an
invented office product, policy and customer request. No real customer records or
personal data are included. They are original project fixtures under the existing
repository Apache-2.0 license. The data directory is well below 100 MB.

Recorded model responses are in `../../evidence/live-cscs-20261003.json`.
No separate external dataset is required for this prototype.
