# Clean-room declaration

Created as a new standalone codebase during the Hack Apertus 2026 event window.

Excluded:
- private SPINNENNETZ-DNA source code
- private Drive/Docs content
- legal, debt-enforcement, family, health, customer or private email data
- credentials, API keys, secrets or tokens
- private routing/governance documents
- private runtime endpoints

Only general ideas are reused: source-aware work, human approval boundaries, verification, and explicit outcome states. They are reimplemented here from scratch.

Only this clean-room folder is intended for possible hackathon publication.
